# Rehab- und Trainingstool

Ein modulares Werkzeug für die individuelle Trainings- und Rehabilitationsplanung. Es soll helfen, Klienten systematisch vom aktuellen Leistungs- und Belastungszustand zu ihrem individuellen Ziel zu führen. Grundlage sind eine Anforderungsanalyse und eine kontrollierte Steigerung der Belastbarkeit (Graded Exposure).

Das Tool unterstützt die fachliche Entscheidungsfindung. Es stellt keine Diagnosen und trifft keine Trainingsentscheidungen.

## Stand

**Phase 1: Produktkonzept und Architektur.** Es gibt noch keinen Code.
